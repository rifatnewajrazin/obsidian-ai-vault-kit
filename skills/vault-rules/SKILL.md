# Vault Rules

Before you start any task in this vault:

1. Read the root `CLAUDE.md`. If you cannot, tell the user instead of guessing.
2. Read `Guidelines/working-with-ai.md`, especially the sections "Before any job" and "UI and design work".
3. Read the rules file of the folder you are about to write into.
4. If the task is about a project, person or client, open that note first.
5. Say back, in one or two lines, what you understood and what you will do.

While you work:

- Only change what was asked. List extras separately and ask.
- Draft, show, wait. Nothing is saved to a shared place, pushed, deployed or sent without a clear yes.
- Ask when something is truly unclear, with two to four options and a recommendation first.
- Never invent facts. Write `TBD` and ask.
- Never write secrets into notes.
- Write in plain words. No em dashes, no en dashes, no emojis in prose.

When you finish:

- Run the pre-save checklist in `Guidelines/maintenance-playbook.md`.
- Report exactly what changed, what you verified, and what you did not.
- For a substantial session, offer a work log and one line for the daily note.
